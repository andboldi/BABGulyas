This project aims to solve the problem proposed in the Urban Elements ReID Challenge 2026: the visual re-identification of urban infrastructure and traffic signs. The task is to match images of the exact same physical object taken under varying lighting, camera angles, and weather conditions. Because standard signs share identical designs, the model cannot rely on general object categories; it must instead detect unique visual signatures like surface wear, scratches, stickers, and mounting hardware. For each query image, the system searches an unindexed gallery database and returns the top 100 candidate matches, evaluated by mean Average Precision (mAP). The primary goal is help automate municipal asset tracking and street infrastructure maintenance.
